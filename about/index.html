Yellowstone Sound Atlas

About

Yellowstone Sound Atlas is a public, unofficial static web project that organizes Yellowstone National Park sound recordings into a playable route. The project emphasizes listening, specimen metadata, source credit, and plain files that agents and search crawlers can read without JavaScript.

The atlas currently includes 61 route stops across thermal features, birds, wildlife, water, weather, human traces, and ambient soundscapes. The interface presents each stop as a specimen stamp with field-note copy, direct playback, theme navigation, and share URLs.

Source materials come from the National Park Service Yellowstone sound library. This site is not an official National Park Service product. If any file, credit, or usage context should be corrected, please open an issue on GitHub.
