Yellowstone Sound Atlas

Documentation

Yellowstone Sound Atlas is an unofficial, public static atlas for Yellowstone National Park sound recordings. It is built as a browsable listening route, not as a hosted account service.

Use the atlas

Open /atlas/ to browse the stamp player, switch specimen themes, play recordings, and share individual specimens. Static share pages live under /atlas/share/{id}/.

Use the data

Fetch /atlas/dawn-to-night.json for structured metadata. Fetch /llms-full.txt for agent context and /openapi.json for a typed description of the public static GET resources.

Source and rights

Source materials come from the National Park Service Yellowstone sound library. NPS labels these audio files as public domain, but downstream users should verify rights and third-party restrictions for their own use.

Limitations

YSL has no OAuth, MCP server, A2A endpoint, account dashboard, write API, payment flow, webhooks, or private data access. Agents should treat the project as a read-only public archive.
