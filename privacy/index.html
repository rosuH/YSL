Yellowstone Sound Atlas

Privacy

Yellowstone Sound Atlas is a static public website. The project does not provide accounts, collect form submissions, run a project-owned analytics script, store private user profiles, or process payments.

Visiting the site may still create ordinary network logs or cache records at infrastructure providers such as GitHub Pages, Cloudflare, browsers, internet service providers, or other intermediaries. Those systems are outside the project code in this repository.

Audio playback and file downloads are served from public static paths. If you contact the project through GitHub issues, the information you post is governed by GitHub's terms and privacy policy.

For removals or corrections, use the GitHub issue tracker.
